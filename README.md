# Fashion MNIST Classifier

Веб-застосунок для класифікації зображень одягу з датасету **Fashion MNIST** за допомогою навчених нейронних мереж.

Застосунок створений за допомогою **Streamlit** та дозволяє користувачеві завантажити власне зображення, вибрати модель та отримати результат класифікації.

## Моделі

У проєкті використовуються дві навчені моделі:

- **CNN (Convolutional Neural Network)**
- **VGG16**

Моделі збережені у форматі `.keras` та завантажуються під час запуску застосунку.

## Класи Fashion MNIST

Моделі класифікують зображення за 10 класами:

| № | Клас |
|---|---|
| 0 | T-shirt/top |
| 1 | Trouser |
| 2 | Pullover |
| 3 | Dress |
| 4 | Coat |
| 5 | Sandal |
| 6 | Shirt |
| 7 | Sneaker |
| 8 | Bag |
| 9 | Ankle boot |

## Функціональність

Веб-застосунок дозволяє:

- вибрати модель **CNN** або **VGG16**;
- переглянути графіки процесу навчання моделі;
- переглянути **Training Accuracy** та **Validation Accuracy**;
- переглянути **Training Loss** та **Validation Loss**;
- завантажити власне зображення у форматі JPG, JPEG або PNG;
- відобразити завантажене зображення;
- виконати попередню обробку зображення відповідно до вхідного шару моделі;
- класифікувати завантажене зображення;
- показати передбачений клас;
- показати ймовірність передбачення;
- переглянути ймовірності для всіх класів Fashion MNIST.

## Встановлення

### 1. Створення віртуального середовища

```bash
python -m venv .venv_tf
```

### 2. Активація середовища

Для macOS / Linux:

```bash
source .venv_tf/bin/activate
```

Для Windows:

```bash
.venv_tf\Scripts\activate
```

### 3. Встановлення бібліотек

```bash
pip install tensorflow streamlit pandas numpy matplotlib pillow
```

## Запуск застосунку

У терміналі необхідно перейти до папки проєкту та виконати:

```bash
python -m streamlit run app.py
```

Після запуску Streamlit відкриє веб-застосунок у браузері.

## Попередня обробка зображень

Перед класифікацією завантажене зображення автоматично приводиться до формату, який очікує вибрана модель.

Для grayscale-моделі зображення перетворюється до розміру:

```text
28 × 28 × 1
```

Перед передачею у модель додається batch dimension:

```text
(1, 28, 28, 1)
```

Значення пікселів нормалізуються до діапазону `[0, 1]`.
